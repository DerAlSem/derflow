# dertext — правка русского текста до нативности

## Суть

Русский текст бывает формально грамотным, но **нерусским**: собран по правилам,
а не на слух (translationese и канцелярит). Пример: «игроцкий портал» вместо
«портал игрока». Ошибки нет — «мы так не говорим».

**Ядро — разделение ролей:**
- **Детектор (ты, агент)** — распознать подозрительный паттерн. Это pattern-match,
  даётся даже без идеального уха.
- **Сертификатор (пользователь-носитель)** — подтвердить, что замена звучит
  по-русски. Только его «да» делает правку истиной.

**Железное правило против самообмана:** никогда не считай свой вариант «правильным
русским» без подтверждения носителя. Ты обучен на той же кривой выборке, что и
исходный текст, — самоодобрение закрепит акцент. Твоя оценка «теперь по-русски»
ничего не стоит; стоит только ратификация пользователя.

## Когда звать / когда нет

- **Звать:** русский текст, который надо сделать нативным (сайт, UI, описание, пост).
- **НЕ звать:** не-русский текст; орфография/грамматика (модель и так не пишет
  «карова»); задача «перевести» (это перевод, не правка); текст «продать» —
  `copywriting`; «объяснить» — `documentation-expert`.

## Детектор — таксономия пороков

| Порок | Признак | Пример → правка |
|---|---|---|
| **Калька** | конструкция/идиома/порядок из английского | «сильное мнение» → «чёткая позиция»; «в случае если» → «если» |
| **Выдуманный композит** | прилагательное/существительное слеплено от роли вместо падежа/оборота | «игроцкий портал» → «портал игрока»; «+бэк-добавка» → «ещё и бэк трогать» |
| **Канцелярит** | нагромождение отглагольных существительных; «осуществление», «данный», «является» | «осуществление управления турнирами» → «управлять турнирами» |
| **Ложная гладкость** | грамматически ровно, но пусто, вода | вырезать |
| **Не тот регистр** | сухо-официально там, где носитель скажет просто | «произвести обращение» → «написать» |

## Две породы правил (ключевое различие)

- **Механическая замена** — калька/композит/канцелярит → фиксированная замена.
  Применяй уверенно: это pattern-match, не суждение о вкусе.
- **Смысловая развилка** — два варианта существуют, но значат **разное**. НЕ меняй
  молча — **спроси пользователя по смыслу**. Пример: «открытые пункты» = ещё
  обсуждать; «висит N задач» = уже решили, отложили. Это не стиль, а значение.

## Процедура (по умолчанию: диагноз → ратификация → чистовик)

1. **Прогон.** Пройди текст детектором + сверь с набором правил
   (`rules.md` — читать при каждом прогоне).
2. **Диагноз.** Выдай список пороков: каждый — с названием, местом в тексте и
   предложением. Механические — с готовой заменой; смысловые развилки — вопросом,
   **не заменяй молча**.
3. **Ратификация.** Жди `±` пользователя и его собственные варианты. Его версия
   важнее твоей — она станет якорем правила.
4. **Чистовик.** Отдай итог только по ратифицированным правкам.
5. **Обучение.** Каждую подтверждённую правку сожми в правило с **живым якорем от
   пользователя** и допиши в `rules.md`. Только ратифицированное → `trusted`. Твоё
   неподтверждённое подозрение — `provisional`, в доверенные не пишется.

## Как копить, чтобы не жечь токены

- Копи **правила** (дистилляция), не сырые пары «до/после». Русских пороков
  конечное число → набор сходится к ~30–50 и выходит на плато.
- Всё живёт в `rules.md`, грузится только на прогоне. Вне вызова — ноль токенов.
- Совпало с существующим правилом → набор не растёт. Новое → медленный прирост.

## Частые ошибки

- **Самому себе ставить зачёт** — «теперь звучит по-русски» без носителя. Запрещено.
- **Молча решать смысловую развилку** — потерять значение. Всегда спрашивать.
- **Копить сырой корпус** вместо правил — раздувает контекст.
- **Лезть в орфографию/перевод** — не задача дертекста.
