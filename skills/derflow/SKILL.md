# derflow — роутер

Одна входная дверь для любой задачи разработки. Классифицируй запрос в **полосу**,
отправь нужному специалисту с нужным количеством процесса. Человек описывает
проблему обычными словами и **не обязан** знать, какого агента звать.

Это жадный слой — только маршрутизация. Правила полосы живут в её движке и
подгружаются после выбора.

## Announce-контракт (ОБЯЗАТЕЛЬНО до любой работы)

Две части. Обе.

> **Lane `<id>` → `<agent/skill>` — потому что `<причина в одном придаточном>`.**
> Затем: прочитать движок полосы (таблица ниже) **до первой правки**.

Полоса без прочитанного движка — не полоса, а угадывание: там лежат все оплаченные
уроки, и объявить верный маршрут, не открыв их, значит наступить на те же грабли с
правильной табличкой на груди.

Составная задача → по строке на часть. **Исключение:** простой вопрос («что делает
X?», «как это работает?») — не работа; просто ответь. Без полосы, без анонса.

## Триаж «сломалось» — до выбора полосы (v4.0)

Жалоба на поведение — «не работает», «нет ссылки», «показывает не то» — **сама
по себе полосой не является**. Один симптом бывает тремя разными задачами, и
срочность их не различает. Три вопроса, от дешёвого к дорогому:

1. **Выражает ли домен то, чего не хватает?** Есть ли у сущности требуемое
   свойство или связь вообще. **Нет → это не баг, а пробел модели → полоса C.**
2. **Механизм работает, но не доехал до поверхности?** Значение считается, но не
   выводится; связь есть, но не отрисована. → **полоса B.**
3. **Механизм ломается?** Тогда — и только тогда — развилка по срочности:
   - работа встала прямо сейчас → **F · инцидент** (`_ship.md`): хотфикс,
     prod-smoke, ретро-спека после. Обходит требование полного цикла C для денег
     и авторизации;
   - можно потратить время на причину → **Dx · диагностика** (`_lane-c.md`):
     сначала `openspec/specs/<capability>`, затем незакрытые `changes/`, и только
     потом **superpowers:systematic-debugging**. Фикс маршрутизируется как A/B/C.

**Потолок триажа — три вопроса и не больше одного чтения файла.** Не уложился —
это уже Dx, объявляй его. Иначе триаж выродится в расследование, а существует он
ровно затем, чтобы отсечь дешёвое от дорогого.

(Боевое: «тренер сделал серию тренировок, а ссылки на неё нет». Если у серии в
модели нет своего адреса — это фича, а не баг, и хотфикс починит симптом там, где
нужна была C.)

## Классификация интента

| Человек на самом деле просит… | Полоса | Маршрут | Движок |
|---|---|---|---|
| «объясни / что делает X» | **— нет полосы** | просто ответь, без церемоний | — |
| жалоба на поведение | **триаж** | см. раздел выше → B, C, F или Dx | — |
| переименовать, поправить текст, значение конфига | **A · тривиальное** | сделай + тест. Без специалиста, без openspec | — |
| малое изменение, где ты знаешь ЧТО менять (кривая модалка, забытое поле) | **B · малый фикс** | специалист (см. дисамбигуацию) + лёгкий гейт: тест, а для UI — визуальная проверка рендера + коммит. Без openspec | `_gates.md` |
| см. таблицу границы ниже | **C · настоящая фича** | полный цикл openspec. Живая спека обновляется | `_lane-c.md` |
| деплой · миграция · рестарт · рассылка · ротация ключа | **Ops** | ops-гейт. Не полоса авторинга кода | `_ship.md` |

Редкие полосы — во втором уровне ниже. Они срабатывают нечасто, и держать их в
главной таблице значит платить вниманием при **каждой** классификации.

## Граница B/C — проверяемая таблица

Когда неочевидно, малый это фикс или настоящая фича, решает не ощущение размера.
Источник правды — скилл `openspec-rules`; здесь копия, потому что решение
принимается **здесь**, до загрузки любого движка.

| Ситуация | Действие |
|---|---|
| Баг в коде, спека описывает поведение верно | Правь код. Change **не** открывать |
| Баг там, где спеки на область нет | Правь код + `descriptive` спека на затронутую capability после |
| Баг вскрыл, что **спека неверна** | Открывай change — proposal объясняет, почему она была неверна |
| Новая фича или изменение поведения | Всегда change |
| Схема, API, публичный контракт | Всегда change + миграция и back-compat в `design.md` |
| Опечатка, off-by-one, форматирование | Правь напрямую. Без change |

И четыре **независимых** триггера C — достаточно любого одного:

- двусмысленно, **или**
- трогает деньги / авторизацию / биллинг / перс-данные / публичный контракт /
  миграцию схемы, **или**
- дольше полудня, **или**
- многосессионное

Размер — лишь один из четырёх. Однострочная правка биллинга идёт полный цикл;
большая, но однозначная и безопасная — не обязана.

Изменение **без изменения поведения** (чистый рефакторинг, тулинг, doc-only)
объявляется в `.openspec.yaml` заявки как `skip_specs: true` — иначе
`openspec validate` отвергнет её как заявку с нулевой дельтой. Не выдумывай
требование ради валидации.

## Дисамбигуация агентов (выбирай по интенту, не по ключевому слову)

Целей маршрутизации **пять**. Набор мал намеренно: роутер ценен известным и
узким списком, а не полнотой.

| Ситуация | Бери | НЕ |
|---|---|---|
| Строить / добавлять / менять структуру UI или проводку | `frontend-developer` | make-interfaces (полировка), ui-ux-designer (критика) |
| UI работает, но «ощущается дёшево» — отступы, радиусы, движение | `make-interfaces-feel-better` | frontend-developer |
| «Это правильный флоу / вёрстка / доступно ли?» | `ui-ux-designer` | frontend-developer |
| Форма системы, границы, «это надо разделить», файл слишком большой | `system-architect` | `python-pro` (он реализует, а не решает форму) |
| Чего НЕ ХВАТАЕТ (пропуски, забытый случай) | `gap-finder` | `/code-review` (он судит то, что есть) |
| Реализовать/оптимизировать именно Python | `python-pro` | frontend-developer |
| Понять незнакомый / свежесклонированный репо | `explore-code` | system-architect (он критикует свежую спеку, не код) |
| Просветить СВОЙ репо (доки / дебаг / плохие решения) | `audit-code` | `/code-review` (баги на диффе, не ориентация) |
| Баги/корректность + качество того, что ЕСТЬ, на рабочем диффе | `/code-review` (`ultra` = глубоко) | gap-finder |
| Применить переиспользование/упрощение/чистку (качество, не баги) | `simplify` | /code-review |
| Безопасность ожидающих изменений | `/security-review` | `/code-review` |
| Найти корневую причину бага / неожиданного поведения | `superpowers:systematic-debugging` | `/code-review` |
| Сверить реализацию с артефактами заявки | `/opsx:verify` | `/code-review` (он про дифф, этот про полноту и связность) |
| Сделать русский текст нативным (не калька/канцелярит) | `dertext` | copywriting (продаёт), `/code-review` |

**Дизайн против сборки (перекрытие, которое кусается):** `system-architect`
решает *форму*, когда она неочевидна или нова — границы, декомпозиция, поверхность
API. `python-pro` и `frontend-developer` *реализуют*, когда форма уже ясна. Добавить
одно поле или сделать прямолинейный эндпоинт — это **сборка**, не дизайн; тянись к
архитектору, только когда модель данных или контракт действительно требуют решения.

**Домены, где своего агента нет.** Платёжный контур (СБП, ККТ, `KkmServer`) и
российское право (152-ФЗ, ОФД/ФНС, самозанятые) — специалистов под них не
впущено, потому что прежние были написаны под Stripe/PCI и GDPR/EU и про
российский контур только догадывались. Здесь работает **внешне-контрактный гейт**
из `_gates.md`: вендорский референс или захваченный сэмпл до парсера и до
вердикта. Для права — сам закон.

Когда подходят двое — бери **более узкого** и скажи почему в строке анонса.

## Второй уровень — редкие полосы

Срабатывают нечасто. Держать их в главной таблице значит платить вниманием при
каждой классификации, поэтому они здесь.

| Интент | Полоса | Маршрут | Движок |
|---|---|---|---|
| новый проект / «глобальная проекция» | **C-bootstrap** | брейншторм + декомпозиция → засеять базовый `openspec/specs`; дальше фичи текут как C | `_lane-c.md` |
| «нет спеки, а надо менять сшивку X» | **C-adopt** | не документируй репозиторий заранее: пиши дельту **только на то, что меняешь**. Спека густеет по трафику | `_lane-c.md` |
| «заявок накопилось, спека отстала» | **C-drain** | `/opsx:bulk-archive` — архивирует пачкой и **сам детектит конфликты спек**. Триаж до фанаута | `_lane-c.md` |
| «этот файл не слишком большой / дизайн нормальный?» | **D · консультация** | `system-architect` (структура) или `simplify` (чистка) → вердикт. Ничего не меняет | — |
| «мы долго строили — проаудируй всё» | **E · аудит** | многомерный ревью, либо `/code-review ultra` → ранжированные находки | — |
| «а можно ли вообще X? попробуй» | **Spike** | одноразовая сборка-чтобы-узнать: без гейта, без коммита → **вердикт** → перезаход как C, либо выбрасывается | — |
| «разберись в незнакомом репо · онбординг» | **Orient · explore** | `explore-code` — ленивая трассировка одного пути; отдаёт seams+paths. Фаза, не полоса | — |
| «просветить *весь* свой репо» (цель — сам обзор) | **Orient · audit** | `audit-code` — граф+churn+`gap-finder` по топ-N. **Дорогой: Workflow-фанаут, ставь потолок** | — |

Все они **ничего не отгружают**. Диагностика, консультация, аудит, фазы Orient и
вердикты Spike дают находки, и каждая принятая **перезаходит** как A/B/C.

**Docs — не полоса.** Источник правды один и это `openspec/specs`. Разводи по цели:

- точечные доки, README, описание API → **B**, без специалиста: это письмо, а не
  проектирование. Русский текст прогоняется через `dertext`;
- «синхронизировать доки с кодом» → это **C-drain**, а не документирование;
- описать большую существующую систему → сперва спроси, **зачем**. Если чтобы
  менять — это `explore-code` по нужной сшивке, а не документирование целиком.

**«Аудит» — ложный друг; разводи по цели, не по слову.** «Прогони *весь* репо»
как самоцель → `audit-code`, и это **whole-repo фанаут, дорогой by design** (один
воркер на узел). А «сориентироваться, чтобы впилить фичу в область X» — **не тот
интент**: цель — изменение, ориентация лишь разогрев → **scoped `explore-code`**
по этому seam'у, дальше правка течёт как B/C. (Боевое: «аудит код» для турнирной
фичи → 55-воркерный Workflow ≈ 2.9M токенов, когда просили scoped `explore-code`.)

## Движки (читаются после выбора полосы)

| Файл | Что внутри |
|---|---|
| `_lane-c.md` | цикл openspec · reap-гейт и C-drain · спека читается первой · критик-слой (`system-architect`/`gap-finder`) |
| `_ship.md` | инцидент F · expedited≠untested · Ops-гейт · приземление и `land.sh` · деплой-таргет |
| `_parallel.md` | изоляция рабочего дерева · ворктри и их жатва · новый запрос = новая ветка |
| `_gates.md` | verify-гейт · внешне-контрактный гейт · UI = дизайн · «нет X в UI» может = нет X в модели |
| `_capture.md` | граница проект/контекст · self-learning на выходе · гигиена памяти |

**Всегда, независимо от полосы:** `_gates.md`, если полоса отгружает код;
`_parallel.md`, если репо может работаться параллельно (проектный `CLAUDE.md` это
объявляет) — ворктри вырезается **до первой правки**; `_capture.md` в конце.
`_ship.md` добавляется, когда ветка приземляется в общий ствол или трогается
деплой, — а не на каждую правку файла.

## Общие ошибки роутинга

- **Пропустить строку анонса** на настоящей работе → маршрутизация становится чёрным ящиком.
- **Объявить полосу и не открыть её движок** — анонс это половина контракта; вторая половина в том, чтобы правила полосы реально попали в контекст.
- **Загонять простой вопрос в полосу** — «объясни X» это ответ без полосы.
- **`audit-code` как разогрев под фичу** — «аудит» в смысле «помоги понять эту область, чтобы её менять» = scoped `explore-code` по seam'у, а НЕ whole-repo аудит (однажды 2.9M токенов). `audit-code` — когда просвет репо и есть цель.
- **Фанаут `audit-code` без оценки токенов** — «топ-N хотспотов» без хардкапа раздувается до 50+ воркеров; оцени «N × ~50k ≈ X» и поставь потолок ДО запуска Workflow, а не считай урон постфактум.
- **Гнать не тот «explore»** — Lane C explore (дизайн по живой спеке) ≠ Orient explore-code (разведка чужого репо); и никогда не гоняй агентов И руками по одним файлам.

## Deliverable evolves

**v4.3.** Уточняй на живых задачах; когда правило маршрутизации оказывается
неверным или появляется полоса, обновляй эти файлы через
**superpowers:writing-skills**. Новые золотые пути захватывает слой
`self-learning` (`_capture.md`).

**История версий — `CHANGELOG.md` рядом.** Там «почему так решили»: каждая запись
это оплаченный боевой промах с ценой. Здесь — только «что истинно сейчас».
Не сливай их обратно: датированная история, живущая в живом документе, — ровно та
ошибка, которую запрещает правило v3.1 (и которой derflow болел до v3.18).
