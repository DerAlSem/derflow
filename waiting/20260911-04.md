## 22.09.2026 — предикат выписан из памяти, и он оказался УЖЕ СРАБОТАВШИМ

Память `inbound-webhook-map` (ящик `gmb_v2`), глава «Эвотор-push ждёт первых
платежей», даёт узкий смысл прямым текстом: ждали не проводки с провайдером
`evotor`, а **сообщения, дошедшего до приёмника**, и величину «сколько сообщений
на один чек» велено брать из `receipt_meta.push_count` — «она пишется с этой
выкатки». Это и есть предикат; он в пробе.

🔴 **Замер по бою 22.09.2026 — ожидание кончилось ещё ДО заведения строки.**

| величина | значение |
|---|---|
| проводок ЮЛ 4 с `receipt_provider=evotor` | 160 |
| из них с ненулевым `push_count` | **21** |
| первое сообщение | **31.08.2026** |
| последнее сообщение | 19.09.2026 |
| чем выяснена судьба: `push` / `poll` / без отметки | **21** / 1 / 138 |
| носитель `sale` у ЮЛ 4: строк / с отметкой | 2 / 0 |

Строка заведена 11.09.2026 — то есть через одиннадцать дней после первого
сообщения. Замер, на котором она стоит («за сутки в логах прода ноль обращений
к приёмнику»), был верен про СУТКИ и неверен про канал: сообщения идут пачками
по дням, и в выбранные сутки их не было. Однодневное окно тут не датчик.

**Что это открывает.** Незакрытые группы заявки `evotor-receipt-push`
(`~/dev/gmb_v2`) перестали быть заблокированными:

- **6.4** «доля судеб, выясненных сообщением, за сутки не ноль» — измерена:
  push 21 против poll 1, то есть канал не просто жив, а несущий.
- **0.1–0.4** живой сэмпл сообщения — ловить уже есть что.
- **6.2a**, **6.3** — набранных чеков хватает на сравнение.

⚠️ **И одна ловушка в самой величине.** `push_count` инкрементируется ПОСЛЕ
ограничителя частоты (`gmp/crm/api/webhooks/evotor.py`, обе двери: строки ~292
и ~345): сообщение, пришедшее внутри окна `receipt_push_min_interval_sec`,
уходит ранним возвратом и счётчик НЕ трогает. Поэтому `push_count = 1` у всех
21 означает «одно сообщение ВНЕ окна», а не «вендор прислал ровно одно».
Отвечать величиной «сколько сообщений на один чек» она без этой оговорки не
может — иначе это замер, отвечающий не на тот вопрос.

🔴 Строку **не гашу**: `done`/`ack`/`taken` — только по прямой просьбе владельца.
Проба написана и укушена, дальше решает он.
